# Exercises — NumPy arrays

Hands-on practice with NumPy arrays and multidimensional arrays for chemical data analysis.

- [`python_arrays_handson.pdf`](python_arrays_handson.pdf) — create, inspect, index, slice, transform, and analyse one-dimensional and multidimensional datasets, then solve a small system of linear equations.

The exercise uses Python 3 and NumPy. Complete the work in a student script named `h2o2_analysis.py` and run it with:

```bash
python3 h2o2_analysis.py
```

Use the setup and reference material in [`../lab/`](../lab/) before starting.
