# Lab — Python and NumPy arrays

Supporting material for preparing a Python environment and working with NumPy arrays.

| File | Purpose |
| --- | --- |
| [`setup.pdf`](setup.pdf) | Step-by-step Ubuntu, Python 3, virtual environment, and NumPy setup |
| [`arrays_cheat_sheet.pdf`](arrays_cheat_sheet.pdf) | Quick syntax reference for creating, inspecting, indexing, slicing, and calculating with arrays |

After installing NumPy, verify the installation with:

```bash
python -c "import numpy as np; print(np.__version__)"
```

Use these resources with the [`../exercises/`](../exercises/) NumPy arrays practical. The cheat sheet is a syntax reference and does not contain answers to the exercise.
