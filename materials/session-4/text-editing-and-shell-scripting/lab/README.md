# Lab — Text editing and shell scripting

Hands-on data and two reference scripts that complete the tutorial sheet.

| File | Role |
| --- | --- |
| [`basic-walkthrough.sh`](basic-walkthrough.sh) | Line-by-line walkthrough (easier to read) |
| [`advanced.sh`](advanced.sh) | Same tasks in compact Bash (`exercise_{1..3}`, nested `grep`/`awk`) |
| [`handson_files/`](handson_files/) | QE output, names, trajectories |
| [`nickel_data/`](nickel_data/) | Nickel `.out` series and `kine_ener.txt` |
| `handson_files.zip`, `nickel_data.zip` | Archives the scripts unpack into `~/handson/shellscripts/` |

```bash
chmod +x basic-walkthrough.sh advanced.sh
./basic-walkthrough.sh
./advanced.sh
```

Run these from this `lab/` directory. Do the exercise sheet yourself first.
